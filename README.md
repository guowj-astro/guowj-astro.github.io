# Wei-Jian Guo · Academic website

Public website: https://guowj-astro.github.io/

The compiled site is served by GitHub Pages from the root of the master branch.

The NGC 1566 photograph supplies the colour and spiral structure of an illustrative thick stellar disk. The galaxy midplane now coincides with the dusty torus and broad-line region, and a continuous soft volume gives the host a modest thickness when viewed from the side. Its measured image nucleus stays at the scene origin. Added depth is illustrative rather than a measured three-dimensional reconstruction.

The animated Gargantua-inspired nucleus, clumpy dusty streams, polar clouds, region navigation, research content and quantitative response models are retained. Reduced-motion preferences and offscreen rendering suspension remain supported.

Photo credit: ESA/Hubble & NASA. Acknowledgement: Det58. [Source](https://esahubble.org/images/potw1422a/) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The original JPEG is unchanged; displayed colour is mapped into a soft three-dimensional volume, with brightness adjustment and independent AGN overlays. Nuclear structures are not resolved features of this photograph.
