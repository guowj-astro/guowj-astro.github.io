# Wei-Jian Guo — Academic website

Public website: https://guowj-astro.github.io/

This repository serves the compiled static academic homepage through GitHub Pages from the root of the master branch. The site includes five interactive research scenes and WebGL2 black-hole and gas illustrations, with synthetic signals and an accessible reduced-motion mode.

Deployments preserve the full JavaScript and CSS export, including `_next/`, alongside `index.html` and `.nojekyll`. Publish the complete export together so the page and hashed resources stay in sync.

The previous Academic Pages source remains in the repository and its history. `.nojekyll` makes the current compiled site independent of the earlier Jekyll theme.
